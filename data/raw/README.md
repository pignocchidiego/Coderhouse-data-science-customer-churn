# Dataset original

Esta carpeta contiene el dataset original utilizado en el proyecto final de Data Science de Coderhouse.

**Archivo:** WA_Fn-UseC_-Telco-Customer-Churn.csv

**Fuente:** IBM Telco Customer Churn, disponible públicamente en Kaggle.

El dataset contiene 7.043 registros de clientes y 21 variables relacionadas con características demográficas, servicios contratados, antigüedad, facturación y abandono del servicio.

La variable objetivo es `Churn`, que indica si un cliente abandonó la empresa (`Yes`) o permaneció (`No`).
