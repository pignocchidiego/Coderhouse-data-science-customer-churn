# Notebooks de Python

Esta carpeta contiene el notebook del proyecto final de Data Science de Coderhouse.

El análisis comprende:

- Exploración y visualización de datos (EDA).
- Limpieza y preprocesamiento.
- Preparación de variables numéricas y categóricas.
- Entrenamiento de modelos de clasificación.
- Comparación entre Regresión Logística y Random Forest.
- Optimización de hiperparámetros mediante GridSearchCV.
- Evaluación mediante Accuracy, Precision, Recall, F1-score y ROC-AUC.

El objetivo es identificar clientes con mayor riesgo de abandono para apoyar estrategias de retención.
