# Documentación del proyecto

Esta carpeta contiene la documentación del proyecto final de Data Science de Coderhouse.

## Informe final

El informe presenta el desarrollo de un modelo predictivo de abandono de clientes (Customer Churn) en una empresa de telecomunicaciones.

Incluye:

- Contexto del problema y objetivos de negocio.
- Descripción del dataset Telco Customer Churn.
- Análisis exploratorio de datos (EDA).
- Limpieza y preprocesamiento.
- Entrenamiento de Regresión Logística y Random Forest.
- Optimización de hiperparámetros con GridSearchCV.
- Evaluación y comparación de modelos.
- Conclusiones y oportunidades de mejora.

## Tecnologías utilizadas

Python, Pandas, NumPy, Matplotlib, Seaborn y Scikit-learn.
